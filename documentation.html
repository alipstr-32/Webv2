Dokumentasi & Pertanyaan Umum (FAQ)

1. Apakah data saya aman?

Ya. Semua enkripsi dan dekripsi menggunakan Web Crypto API standar industri (AES-256-GCM) yang berjalan langsung di browser Anda. File tidak pernah dikirim ke server luar.

2. Apa itu format .alipenc?

Format kontainer khusus yang menyimpan metadata file asli (nama dan ekstensi) serta ciphertext terenkripsi bersama salt dan IV acak kriptografis.

3. Apa perbedaan Enkripsi dan Obfuscation?

Enkripsi melindungi kerahasiaan data total dengan kunci kriptografi. Obfuscation mengaburkan keterbacaan kode sumber tanpa mengubah fungsionalitas aslinya, bukan enkripsi mutlak.
